## 題目描述

某所學校有 `N` 位學生。第 1 天，有 `F` 位學生聽到一則流言，並開始到處轉述。

每位學生**聽到流言的那一天起，會連續熱衷轉述 `R` 天**：第 `n` 天聽到的人，在第 `n` 到第 `n + R − 1` 天都是「熱衷者」，**從第 `n + R` 天起失去興趣**，不再轉述。聽過流言的人**不會再聽到第二次**，也不會再變回熱衷者。

傳播規則如下，`p` 是傳播比例（百分比）：

- **第 1 天**：新聽到的人數就是 `F`，沒有人失去興趣。
- **第 `d` 天（`d ≥ 2`）**，嚴格依照以下順序：
  1. **失去興趣人數** = 第 `d − R` 天新聽到的人數；如果 `d − R < 1`，則為 0。
  2. **新聽到人數** = ⌊ 昨天結束時的熱衷人數 × `p` / 100 ⌋（無條件捨去）。但**不能超過還沒聽過流言的學生人數**；超過時就等於剩下沒聽過的人數。
  3. **今天的熱衷人數** = 昨天結束時的熱衷人數 + 今天新聽到人數 − 今天失去興趣人數。

請輸出每一天的熱衷人數、新聽到人數、失去興趣人數，以及整段期間總共有多少位學生聽過流言。

## 輸入格式

第一行有兩個整數 `N F`：學生人數、第 1 天聽到流言的人數。

第二行有三個整數 `D R p`：觀察天數、熱衷天數、傳播比例（百分比）。

## 輸出格式

輸出 `D + 1` 行。

第 1 到 `D` 行：第 `d` 行輸出四個整數 `d active new lost`，分別是第幾天、當天結束時的熱衷人數、當天新聽到人數、當天失去興趣人數，中間以一個空白隔開。

第 `D + 1` 行：一個整數，代表 `D` 天內總共聽過流言的學生人數（包含第 1 天的 `F` 人）。

## 限制

- `10 ≤ N ≤ 10000`
- `1 ≤ F ≤ N`
- `1 ≤ D ≤ 30`
- `1 ≤ R ≤ 20`
- `0 ≤ p ≤ 300`

## 備註

例如 `R = 3` 時，第 1 天聽到的人在第 1、2、3 天熱衷，第 4 天失去興趣。
