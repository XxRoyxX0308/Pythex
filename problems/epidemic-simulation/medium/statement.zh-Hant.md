## 題目描述

海上有三座島 A、B、C，由一條環狀渡輪航線連接：**A → B → C → A**。一場流感在三座島上流行，每座島的居民分成三類：

- **易感者**：可能被感染的人。
- **免疫者**：天生免疫或已經康復的人，不會再被感染。
- **確診中**：正在生病的人。

**第 1 天**：島的人口為 `P`、免疫比例為 `a`（百分比），則免疫者 = ⌊`P` × `a` / 100⌋，其餘都是易感者。接著該島有 `F` 位易感者確診（第 1 天的新增確診就是 `F`），沒有人康復，**不移動**。

**第 `d` 天（`d ≥ 2`）**，每座島嚴格依照以下順序：

1. **同步移動**：每座島各有移動比例 `m`（百分比）。該島移往下一座島的易感者 = ⌊易感者 × `m` / 100⌋，免疫者 = ⌊免疫者 × `m` / 100⌋，兩類分開計算，移動後保留原本的狀態。**確診中的人不移動**。三座島**同時**移動：先用移動前的人數算出三座島各自要走的人數，再一起完成移動。
2. **康復**：第 `n` 天確診的人，在第 `n + R` 天康復並成為免疫者。所以今天的康復人數 = 這座島第 `d − R` 天的新增確診（`d − R < 1` 時為 0）。
3. **新增確診**：設 `S` 為這座島**前一天結束時**的確診中人數，`T` 為前一天結束時的人口，`I` 為前一天結束時的免疫者人數（包含前一天康復的人），則
   新增確診 = ⌊ `S` × `c` × (`T` − `I`) / (100 × `R` × `T`) ⌋。
   新增確診**不能超過這座島移動完之後的易感者人數**，超過時就等於易感者人數。若 `T = 0`，新增確診為 0。
4. **更新**：確診中人數 = 前一天的確診中人數 + 今天新增確診 − 今天康復人數。新增確診的人從易感者變成確診中，康復的人從確診中變成免疫者。

這裡 `c / 100` 代表每位病人在整個病程中平均會傳染的人數。

請輸出每座島每一天的確診中人數、新增確診、康復人數，最後輸出三座島總共的新增確診人數，以及三座島**確診中人數加總最多的一天**。

## 輸入格式

共 7 行：

1. 三個整數 `PA PB PC`：三座島的初始人口。
2. 一個整數 `D`：天數。
3. 三個整數 `FA FB FC`：三座島第 1 天的確診人數。
4. 一個整數 `c`：傳染力（每位病人平均傳染 `c / 100` 人）。
5. 一個整數 `R`：生病天數。
6. 三個整數 `aA aB aC`：三座島第 1 天的免疫比例（百分比）。
7. 三個整數 `mA mB mC`：三座島的移動比例（百分比）。

## 輸出格式

輸出 `3 × D + 1` 行。

前 `3 × D` 行：每天依序輸出島 A、B、C 各一行，每行五個欄位 `d X sick new recovered`：第幾天、島的代號（`A`、`B` 或 `C`）、當天結束時的確診中人數、當天新增確診、當天康復人數，中間以一個空白隔開。

最後一行：兩個整數，以一個空白隔開。第一個是 `D` 天內三座島的新增確診總和（包含第 1 天的 `FA + FB + FC`）；第二個是三座島確診中人數加總最大的那一天。**若有多天平手，輸出最早的一天。**

## 限制

- `100 ≤ PA, PB, PC ≤ 10000`
- `1 ≤ D ≤ 20`
- `10 ≤ c ≤ 200`
- `1 ≤ R ≤ 20`
- `0 ≤ aA, aB, aC ≤ 99`
- `1 ≤ F ≤ P − ⌊P × a / 100⌋`（每座島各自成立）
- `0 ≤ mA, mB, mC ≤ 100`

## 備註

所有除法都是整數除法，結果無條件捨去。例如前一天島 A 有 80 位病人、人口 1200、免疫者 180，`c = 140`、`R = 4`，則新增確診 = ⌊80 × 140 × 1020 / (100 × 4 × 1200)⌋ = 23。
