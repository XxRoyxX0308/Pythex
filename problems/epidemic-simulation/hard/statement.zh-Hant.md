## 題目描述

一座蜂場把 `K` 個蜂箱排成一圈，編號 1 到 `K`。健康的蜜蜂常常「迷航」飛進隔壁的蜂箱：**蜂箱 `i` 的蜂飛往蜂箱 `i + 1`，蜂箱 `K` 的蜂飛回蜂箱 1**。一種蜂病在蜂場中傳播，每個蜂箱的蜜蜂分成三類：

- **易感蜂**：可能被感染的蜂。
- **抗病蜂**：天生抗病或已經康復的蜂，不會再被感染。
- **生病蜂**：正在生病的蜂。

**第 1 天**：蜂箱的蜂數為 `P`、抗病比例為 `a`（百分比），則抗病蜂 = ⌊`P` × `a` / 100⌋，其餘都是易感蜂。接著該蜂箱有 `F` 隻易感蜂生病（第 1 天的新增病例就是 `F`），沒有蜂康復，**不移動**。

**第 `d` 天（`d ≥ 2`）**，每個蜂箱嚴格依照以下順序：

1. **同步移動**：每個蜂箱各有移動比例 `m`（百分比）。該蜂箱飛往下一箱的易感蜂 = ⌊易感蜂 × `m` / 100⌋，抗病蜂 = ⌊抗病蜂 × `m` / 100⌋，兩類分開計算，飛過去後保留原本的狀態。**生病蜂不移動**。所有蜂箱**同時**移動：先用移動前的數量算出每個蜂箱各自要飛走多少，再一起完成移動。
2. **康復**：第 `n` 天生病的蜂，在第 `n + R` 天康復並成為抗病蜂。所以今天的康復數 = 這個蜂箱第 `d − R` 天的新增病例（`d − R < 1` 時為 0）。
3. **新增病例**：設 `S` 為這個蜂箱**前一天結束時**的生病蜂數，`T` 為前一天結束時的蜂數，`I` 為前一天結束時的抗病蜂數（包含前一天康復的蜂），則
   新增病例 = ⌊ `S` × `c` × (`T` − `I`) / (100 × `R` × `T`) ⌋。
   新增病例**不能超過這個蜂箱移動完之後的易感蜂數**，超過時就等於易感蜂數。若 `T = 0`，新增病例為 0。
4. **更新**：生病蜂數 = 前一天的生病蜂數 + 今天新增病例 − 今天康復數。

養蜂人想知道每個蜂箱疫情**最嚴重的時刻**：生病蜂數的最大值，以及它**第一次**出現在第幾天。另外也要知道整季的新增病例總數，以及最後一天結束時還有多少生病蜂。

## 輸入格式

第一行有四個整數 `K D R c`：蜂箱數、天數、生病天數、傳染力（每隻生病蜂在整個病程平均傳染 `c / 100` 隻）。

接下來 `K` 行，第 `i` 行有四個整數 `P F a m`：蜂箱 `i` 的初始蜂數、第 1 天的病例數、抗病比例（百分比）、移動比例（百分比）。

## 輸出格式

輸出 `K + 1` 行。

第 `i` 行（`1 ≤ i ≤ K`）：三個整數 `i peak day`，分別是蜂箱編號、這個蜂箱在第 1 到 `D` 天中，每天結束時生病蜂數的最大值，以及最大值出現的日子。**若有多天平手，輸出最早的一天。**

第 `K + 1` 行：兩個整數，第一個是 `D` 天內所有蜂箱的新增病例總和（包含第 1 天的 `F`），第二個是第 `D` 天結束時所有蜂箱的生病蜂總數。

每行數字之間以一個空白隔開。

## 限制

- `2 ≤ K ≤ 10`
- `1 ≤ D ≤ 10⁴`
- `1 ≤ R ≤ 10⁴`
- `10 ≤ c ≤ 200`
- `100 ≤ P ≤ 10⁵`
- `0 ≤ a ≤ 99`
- `1 ≤ F ≤ P − ⌊P × a / 100⌋`
- `0 ≤ m ≤ 100`

## 備註

所有除法都是整數除法，結果無條件捨去。最大資料有 10 個蜂箱、10⁴ 天、`R` 可達 10⁴。每天都掃過所有過去的病例批次、或把最近 `R` 天的新增加總，都會超過時間限制。
